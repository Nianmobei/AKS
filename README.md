# AKS

AKS 助手项目的整理快照。包含云端对话、记忆、角色日程、自主阅读与本地交互页面的部分源代码。

本快照是经过筛选的初步源码归档，尚不是完整的一键安装包：运行依赖、设备桥接、角色模型、云端资料和配置需要单独整理。代码已移除原有 QQ 默认号码，部署时须在私密环境中提供 AKS_OWNER 和 AKS_BOT。不要把 API 密钥、QQ 登录态、私聊、个人文档或数据库提交到仓库。

目录：
- cloud/aks-tencent：云端核心模块。
- research/aks-autonomy/prototype：本地对话及画面分享界面原型。

角色模型可能包含第三方游戏资源，未纳入公开仓库；使用和再分发需核实权利。

- gogh-conversion/airi-integration/patch：部分桌宠外观、动作与 AIRI 集成补丁；不含 AIRI 应用本体或游戏模型。

本快照未包含依赖包、安装器、旧备份、私人聊天、凭据、云服务器数据、第三方角色模型和有敏感配置的部署脚本；不能作为完整恢复备份。浏览器识图/本地 OCR 的端到端运行尚未验收。

## 对话与自主活动配置

固定人格统一在 `cloud/aks-tencent/persona.json` 修改，服务重启后生效。云端对话、QQ、主动分享和自主阅读复用该配置；AIRI 导入保留聊天及历史模型参数用于归档；实际模型、人设和上下文预算由云端配置决定，导入值不再覆盖云端。独立运行、未连接 AKS 的 AIRI 不受此配置控制。

- `AKS_CONTEXT_TOKENS`：整轮上下文估算预算，默认 24000，包含工具定义、输出预留和 1000 token 余量。按 UTF-8 字节保守估算，并非模型精确分词；实际 usage 仍由提供商返回。超限时从最旧整轮对话开始移除，不拆散工具调用；当前轮或固定提示本身超限则明确失败，避免静默截断用户输入。原始历史仍保存，可检索。
- `AKS_OUTPUT_TOKENS`：单次输出上限，默认 2600，各任务原有较小上限仍保留。
- `AKS_SPEAK_PROBABILITY`：主动搭话本地触发概率，默认 0.35，范围 0—1。沿用原有日程、静默时段、闲置 45 分钟、每日上限、发送开关和去重；每 15 分钟最多判断一次，桌面与 QQ 对话共享冷却记录。
- `video_read` 和 `web_read` 的标准 B 站视频链接分支读取第一分P公开简介与可用字幕，字幕带时间戳和覆盖范围。字幕缺失时明确降级到简介；目前未接入抽帧、OCR、音轨转写及登录态，不自动评论或发布。

真实 B 站字幕可用性取决于平台公开接口；抽帧、音轨转写仍未接入。

## 云端发布与本地最小支持

发布版本以云端 `release.json` 为准，当前源版本为 `0.2.0`，人格修订号独立保留。云端 `/health` 返回发布版本、人格摘要哈希、协议及生效的模型/预算配置；鉴权后的 `/release` 返回相同发布信息。本地 `/release` 只转发并缓存云端信息五分钟，不生成自己的权威版本。

云端负责对话生成、人格、持久化对话与记忆、阅读、生活调度、主动搭话判断和视频字幕读取。本地保留 AIRI 角色/音频/画面采集及设备认证、SSH 桥接和依赖本机项目的工作台适配；不新增本地推理模型或媒体后台常驻服务。工作通道沿用独立记忆域。

云端环境可设置 `AKS_MODEL`、`AKS_TEMPERATURE`、`AKS_TOP_P`、`AKS_CONTEXT_TOKENS`、`AKS_OUTPUT_TOKENS`。人格改动修改云端 `persona.json` 后重启。不要把云端私密账号、凭据和数据回写公共源码。

发布步骤：

1. 运行 `node scripts/build-cloud-release.mjs` 生成 `dist/` 中的源码变更包和安装脚本；包内不含数据库、登录态、环境文件或密钥。
2. 将两份文件上传现有云端 `/root/`，先执行 `python3 /root/install-cloud-release.py check`。安装器以现有 `/opt/aks` 为基线合并，冲突则停止；保留云端专有设置，并在无网络的临时容器中运行语法检查及完整测试。若有既有失败，必须与未修改基线对照，任何新增失败均阻止发布。
3. 执行同一脚本的 `apply` 模式。安装器备份源码、Compose 和 SQLite，再更新现有容器挂载；健康检查不通过则恢复旧代码与 Compose。不会回滚或覆盖运行中的用户记忆。每次发布在云端生成 `release-manifest.json`，记录实际源文件 SHA-256，以便核对漂移。
4. 本地仅通过 `scripts/update-device.ps1` 增量更新版本状态桥接和页面，保留本机授权、工作记录及 AIRI 安装；脚本会备份被替换的文件，并仅重启该安装下的设备桥接进程。

新增发布版本时一起更新 `release.json` 和包版本，构建脚本会检查两者一致。更改生产代码后重新构建并发布，避免在云端直接修改后遗漏清单；云端保留的运维脚本和私密配置不进入源码包。
